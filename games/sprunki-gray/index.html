角色概览

Gray（格雷）是 Sprunki 中气质最独特的角色之一：通体灰色、表情冷静，话不多但存在感极强。在一众色彩鲜艳的角色里，Gray 的性冷淡风反而让他拥有大批忠实粉丝。

社区给 Gray 的标签是神秘、忧郁、深夜电台——他的音乐盒式低音 loop，自带一种孤独又高级的氛围，是很多氛围向混音的灵魂。

音色与混音定位

Gray 的定位是低音氛围。他的 loop 是缓慢、深沉的音乐盒式低音，为混音提供厚度和情绪底色。

在混音中的建议用法：

  • 厚度来源：混音听起来太飘？加 Gray。他的低音能立刻让作品有分量感。
  • 情绪底色：想做忧郁、深夜、电影感？Gray 是氛围发动机。
  • 慢热型：Gray 的 loop 偏慢，适合 BPM 偏低的作品；快节奏混音里用他要小心拖拍。

搭配技巧

深夜电台：Gray + Wenda + Sky——低音、女声、氛围，忧郁唯美风的标配，适合深夜向视频。

低频双层：Gray + Mr. Tree，两个低频角色叠出电影感厚度，注意音量别爆。

恐怖模式利器：Gray 走调的音乐盒是恐怖模式里最瘆人的声音之一，配合暗黑视觉，反差拉满。

别和快节奏硬配：Gray 偏慢，硬塞进高速 funk 混音会打架，选慢歌用他。

常见问题 FAQ

Gray 的音色有什么特点？

缓慢深沉的音乐盒式低音，自带忧郁高级的氛围，是 Sprunki 里辨识度最高的低音角色。

Gray 为什么人气高？

反差感。在一众鲜艳角色里，他的灰色冷静风独树一帜，加上深夜电台气质，吸了一大批氛围向粉丝。

Gray 在恐怖模式下什么样？

灰色加深出现裂纹，音乐盒走调、低音变阴森，是恐怖模式里最瘆人的声音之一。

Gray 适合快节奏混音吗？

不太适合。他的 loop 偏慢，硬配快节奏会打架。慢歌、氛围向作品才是他的主场。

Gray 和 Mr. Tree 怎么选？

都要低频厚度可以叠用，但注意音量。只要一个的话，Gray 更有情绪，Mr. Tree 更纯粹做低频。
