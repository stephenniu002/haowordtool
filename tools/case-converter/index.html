什么是大小写转换？

大小写转换是把文本中的字母在大小写之间切换的操作。不同场景需要不同的格式：编程用 camelCase 和 snake_case，标题用 Title Case，URL 用 kebab-case。

大小写格式说明

UPPERCASE（全大写）

所有字母转为大写。常用于强调、缩写、标题。

lowercase（全小写）

所有字母转为小写。常用于邮箱地址、用户名。

Title Case（标题格式）

每个主要单词首字母大写，小词（a、an、the、and、of 等）保持小写。用于标题、书名、文章标题。

Sentence case（句子格式）

只有第一个单词的首字母大写，其余小写。用于句子、段落。

camelCase

首字母小写，后续单词首字母大写，无空格。用于 JavaScript、Java 变量名。

PascalCase

每个单词首字母都大写，无空格。用于类名、组件名。

snake_case

单词间用下划线连接，全小写。用于 Python 变量、数据库字段。

kebab-case

单词间用连字符连接，全小写。用于 URL、CSS 类名、HTML 属性。

常见问题 FAQ

什么是 Title Case？

Title Case 是指每个主要单词的首字母大写，冠词、介词、连词等小词保持小写。常用于标题和书名的格式化。

camelCase 和 PascalCase 有什么区别？

camelCase 首字母小写（如 myVariableName），PascalCase 首字母大写（如 MyVariableName）。两者都用于编程变量和类名。

snake_case 和 kebab-case 怎么用？

snake_case 用下划线连接（如 my_variable_name），常用于 Python 和数据库字段。kebab-case 用连字符连接（如 my-variable-name），常用于 URL 和 CSS 类名。
