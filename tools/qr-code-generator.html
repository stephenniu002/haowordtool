What a QR Code Actually Is

A QR code is a two-dimensional barcode: a grid of black and white modules that encodes data together with error-correction information. A scanner reads the grid with a camera, reconstructs the bit pattern, applies error correction to repair any misread modules, and returns the original text.

That is the whole mechanism. There is no link shortener involved, no tracking pixel, no account and no server. A QR code generated here contains exactly the text you typed and nothing else, which is why it never expires.

Static vs Dynamic QR Codes

A static code encodes the destination directly. The URL lives inside the grid. It never expires, works offline from the printed page, cannot be edited, and cannot be tracked. This generator produces static codes.

A dynamic code encodes a short redirect URL owned by a service, which then forwards to your real destination. The advantage is that you can change the destination after printing. The cost is that the code dies when the service dies, and every scan is logged by that service.

For anything permanent — packaging, signage, business cards, printed manuals — a static code is the safer choice, because its lifespan is bounded only by the paper it is printed on. Dynamic codes make sense when you genuinely need to retarget an already-printed asset, and when you accept the dependency.

How Much Data Fits

Capacity depends on the encoding mode and the error-correction level. Numeric data packs most densely, then alphanumeric, then byte mode for arbitrary text. As a practical guide, a typical QR code comfortably holds a URL of around 100 characters, and roughly 300 characters of plain text remains scannable at normal print sizes. Larger payloads force a denser grid with smaller modules, which becomes hard to scan from a distance and hard to print cleanly.

If your content is long, do not force it into the grid. Host the content at a short URL and encode the URL instead. The code stays sparse, and sparse scans reliably.

Error Correction, in Plain Terms

QR codes carry redundant data so that a partially damaged code can still be read. The four levels are L (about 7 percent recovery), M (15 percent), Q (25 percent) and H (30 percent). Higher correction means a denser code for the same content.

Use higher correction when the code will be printed small, placed on a curved surface, exposed to weather, or likely to be partly covered — a logo in the centre, for instance. Use lower correction when the code must stay as sparse as possible, such as on a poster read from several metres away.

Five Things That Break Scanning

  • Too little contrast. Dark modules must be clearly darker than the background. Inverted codes (light on dark) fail on many scanners.
  • No quiet zone. A clear margin of at least four modules on every side is required. Cropping tight to the grid breaks recognition.
  • Non-uniform scaling. Stretching width and height by different factors distorts the module grid beyond repair.
  • Too small in print. Below roughly 2 cm square, phone cameras struggle at any distance. Size the code to the viewing distance, not to the layout.
  • Low print resolution. A code that looks fine on screen can print with blurred module edges. Export at a generous pixel size and print at high DPI.

FAQ

Do QR codes generated here expire?

No. The code encodes your content directly, so it contains no redirect and no service dependency. It works for as long as the encoded text or URL remains valid.

Can I change the destination after printing?

Not with a static code, which is what this generator produces. Changing the destination requires generating a new code. Services that offer editable codes do so by encoding their own redirect URL, which ties the printed code to that service.

Is there a watermark or scan limit?

No. There is no watermark, no scan limit and no sign-up. The downloaded PNG is yours to use commercially.

Why will my QR code not scan?

The most common causes are insufficient contrast, a cropped quiet zone, non-uniform stretching, and printing too small. Test with two different phones before committing to print.

How much text can a QR code hold?

A few hundred characters at typical print sizes. URLs of around 100 characters work comfortably. For longer content, encode a short link to the content rather than the content itself.

Do these codes track who scans them?

No. A static code has no mechanism for reporting scans. If you need scan analytics, you would have to use a dynamic code from a service that provides it.

Can I use the generated code commercially?

Yes. Codes you generate are free to use for personal or commercial purposes.
