Case Types Explained

Uppercase

EVERY LETTER CAPITALIZED. Used for headings, warnings, abbreviations and emphasis. Example: "FREE SHIPPING ON ALL ORDERS".

Lowercase

every letter in small caps. Used for normal body text, email addresses and casual writing. Example: "free shipping on all orders".

Title Case

Each Major Word Capitalized. The standard for book titles, article headlines and YouTube titles. Minor words (a, an, the, and, of) stay lowercase unless first or last.

Sentence Case

Only the first letter of each sentence is capitalized. The default for essays, emails and normal prose. Example: "Free shipping on all orders. No minimum spend."

camelCase

First word lowercase, subsequent words capitalized, no spaces: freeShippingOnAllOrders. The convention for variables and functions in JavaScript, Java and many other languages.

PascalCase

Every word capitalized, no spaces: FreeShippingOnAllOrders. Used for class names, React components and C# types.

snake_case

All lowercase with underscores: free_shipping_on_all_orders. Common in Python, Ruby, database columns and file names.

kebab-case

All lowercase with hyphens: free-shipping-on-all-orders. The standard for URL slugs, CSS classes and HTML attributes.

When to Use Each Case Type

Programming and Code

Match your language's convention: camelCase for JavaScript variables, PascalCase for classes and components, snake_case for Python, kebab-case for CSS classes and URLs.

Headlines and Titles

Use Title Case for article headlines, book titles and video titles. Use UPPERCASE sparingly for banners and call-to-action buttons where you want maximum punch.

Academic Writing

Stick to Sentence case for body text and follow your style guide (APA, MLA, Chicago) for headings. Random capitalization is one of the fastest ways to look unprofessional in a paper.

Social Media

Title Case works well for post hooks and profile headlines. Sentence case reads most naturally in captions. Avoid full UPPERCASE posts — readers interpret it as shouting.

FAQ

What is title case?

Title case capitalizes the first letter of each major word in a headline or title. Minor words like "a", "an", "the", "and" and "of" stay lowercase unless they are the first or last word.

What is the difference between camelCase and PascalCase?

camelCase starts with a lowercase letter (myVariableName) and is common for variables and functions. PascalCase capitalizes every word including the first (MyClassName) and is common for classes and components.
