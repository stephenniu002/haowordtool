Worked example

SOS is ... --- ... — three dots, three dashes, three dots. The spaces between letters matter; the slashes between words are a convention added for readability, not part of the original code.

Morse encodes each character as a sequence of short and long signals. It was designed for a single wire and a human ear, which is why the timing ratios matter as much as the symbols: a dash is three units, the gap between symbols one unit, between letters three, between words seven.

Why the spacing matters

Without separators, ... could be S, or the start of many other characters. This translator uses a single space between letters and a slash between words, which is the convention used in written Morse and the one radio operators read.

What it cannot represent

Accented characters, CJK, and most symbols are dropped rather than transliterated. Morse has no standard encoding for them, and inventing one produces output that no other implementation can read.

Practical uses

Puzzles, teaching signal encoding, and generating decorative text. It is not encryption — anyone with the table decodes it in seconds, and it has been public since 1844.

Spacing is the message

Morse has three levels of separation: a short gap inside a letter, a longer gap between letters, and a longer one still between words. Lose the letter spacing and the same dots and dashes decode into different text, which is why plain concatenation is unreadable even when every character is correct.

The alphabet covers twenty-six letters, ten digits and a handful of punctuation marks; there is no native case and no accents, so accented characters are usually transliterated before encoding. Timing matters on air but not in text: a dash is three units and the gaps are one, three and seven units respectively, which is the detail that makes hand-sent code copyable.
