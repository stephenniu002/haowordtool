Methodology

Transparent matching, stated limits.

We explain what the tool does, what it does not do, and how to verify a result.

1. Normalize the input

Letters are converted to lowercase and spaces are ignored. ? or * counts as one blank. Other characters and racks outside 2–15 tiles produce a visible error; input is never silently truncated.

2. Count letters

The rack and each candidate are stored as letter counts. A candidate passes when every required count is available; blanks cover a limited number of missing counts.

3. Apply search mode

Subset mode accepts words within the selected length range. Exact mode also requires the candidate length to equal the rack length.

4. Rank results

Longer words appear first, followed by a familiar English tile-value score, then alphabetic order. Ranking is deterministic and not presented as artificial intelligence.

5. State the limits

ENABLE includes uncommon, dated and potentially sensitive words. It is not a substitute for the current official lexicon of a tournament, app, school, or publisher. Scores reflect the actual rack: printed tiles contribute their English tile values and blanks contribute zero. Board multipliers, cross-words and bonuses are excluded.

Watch one search: CART? from keystroke to results

Here is exactly what happens when you search the rack CART? — four letters plus one blank — in subset mode with minimum length 5. Every step can be reproduced by hand.

  1. Normalize. The input becomes the lowercase string cart?. The ? is recorded as one blank, never as a letter.
  2. Count. The rack becomes the count table {c:1, a:1, r:1, t:1} plus a blank budget of 1.
  3. Test each candidate. Take the word CRATE: it needs {c:1, r:1, a:1, t:1, e:1}. The rack covers c, r, a and t directly; the single e exceeds the rack by one letter, which fits inside the blank budget of 1. CRATE passes. A word needing two letters outside the rack — CRAFTS needs both f and s — fails.
  4. Score the survivors. Only letters physically on the rack contribute points; the blank contributes zero. For CRATE: C(3) + A(1) + R(1) + T(1) + blank-as-E(0) = 6. This run produces 19 five-letter matches, and most of them score 6 for the same reason — they spend the same four rack letters: ACTOR, BRACT, CARAT, CARET, CARTE, CARTS, CATER, CHART, CRAFT, CRATE, and others.
  5. Rank. All 19 matches have length 5, so length ties; most tile-value scores tie at 6; the remaining order is alphabetic. The ranking is fully deterministic — the same rack always returns the same order, and nothing about it is presented as artificial intelligence.
  6. Render with the blank marked. In each result, the letter supplied by the blank is highlighted, so you can see at a glance that the E in CRATE came from the blank tile.

The tile-value table used for ranking

Ranking uses standard English Scrabble tile values. The table below is the complete set the sorter applies; a word's shown score is the sum of its rack-supplied letters, with blanks always contributing zero:

Worked check: CAT built from CA? scores C(3) + A(1) + blank-as-T(0) = 4. If the same word were built from three real tiles, it would score 5. The one-point difference is the blank's cost made visible, which is why the highlight matters: a high-looking word whose key letter came from a blank is worth less than it appears.

Pitfalls we hit while building and testing

Score the blank after matching, not before. An early version of the ranking computed a word's score from all its letters and only then zeroed the blank's contribution — but it sorted on the pre-zeroed value. CAT from CA? briefly outranked genuine 5-point plays because the blank's T was counted before being removed. The rule is now strict: blanks contribute zero at every stage, including the sort. The visible math (C 3 + A 1 + blank-T 0 = 4) exists so anyone can audit it.

An empty exact-mode result is a UX failure, not a data failure. In testing, the most confusing outcome was an empty list after ticking Exact anagram on a long rack. The data was correct — most long racks genuinely have no full-length anagram — but the empty screen read as "broken tool." If your exact search returns nothing, that is a real answer: untick exact to see the shorter words the rack does contain.

Never substitute a partial dictionary silently. The word list downloads once per page session on the first search. If the download fails — a dropped mobile connection, a blocked request — the tool shows an error instead of searching a half-loaded list. We considered falling back to a small built-in list and rejected it: a partial list would return wrong "no results" answers, and a visible error is always preferable to a silent wrong answer.

Pasted racks carry invisible characters. Racks copied from screenshots or chat apps sometimes arrived with zero-width spaces or smart quotes. Any character outside letters and ?/* produces a visible error rather than a silent truncation. If you see that error, retype the letters by hand before assuming a bug.

Frequently asked questions

Why is this tool's ranking different from another solver's?

Almost always the dictionary, not the algorithm. Two correct solvers fed the same word list return the same matches; the differences come from different lists and different ranking rules. Ours is documented above: length, then tile value, then alphabetic order.

Does the tool learn from my searches or store my letters?

No. Matching runs locally in your browser and no search history is sent to our server. Standard hosting and advertising services may still process technical request data as explained in our Privacy Policy.

Why doesn't a valid word I know appear in the results?

It is outside the bundled ENABLE list, or it was excluded by your mode or length settings. Check the settings first — especially whether Exact anagram is still ticked — then confirm the word in the dictionary your game requires.

Can two blanks be used inside one word?

Yes. Each blank covers one missing letter; a candidate passes when its total deficit is no larger than the number of blanks held. Both blank-supplied letters are highlighted and score zero.

Is the score shown the score I get in a game?

No. It is the base tile sum only: printed tiles at their English tile values, blanks at zero. Board multipliers, crossing words, and bonuses such as the 50-point bingo are excluded, so treat the number as a comparison aid, not a game score.

Dictionary source and coverage

The bundled ENABLE list is distributed as public-domain word data. We retain the upstream file and match unique lowercase a–z entries of 2–15 letters. Read the source record, checksum and licensing references. The file downloads once per page session when you first search. An error is shown if it cannot load; no partial list is silently substituted.
