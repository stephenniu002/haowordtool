Häufige Fragen

Kann ich die Größe ändern?

Der Download ist 260×260 px und lässt sich verlustfrei skalieren.

Läuft der Code ab?

Nein. QR-Codes enthalten die Daten direkt und laufen nicht ab.

Fehlerkorrektur und Größe

QR-Codes enthalten redundant gespeicherte Daten, damit sie auch bei Verschmutzung, Kratzern oder schlechter Beleuchtung lesbar bleiben. Die Fehlerkorrekturstufe L toleriert rund 7 Prozent beschädigte Fläche, M etwa 15, Q rund 25 und H bis zu 30 Prozent. Höhere Stufen erzeugen mehr Module auf gleicher Fläche, wodurch der Code dichter und auf kleinen Etiketten schwerer scanbar wird.

Für gedruckte Materialien gilt als Faustregel: mindestens 2 Zentimeter Kantenlänge auf dem Endprodukt, bei größeren Leseabständen entsprechend mehr. Um den Code herum muss ein Ruhebereich von vier Modulen frei bleiben, sonst erkennen viele Scanner ihn nicht. Wird der Code auf farbigem Hintergrund platziert, braucht es ausreichend Kontrast — dunkle Module auf hellem Grund, nie umgekehrt.

Statisch oder dynamisch

Der hier erzeugte Code ist statisch: Die Zieladresse steckt direkt in den Modulen. Das ist robust und funktioniert ohne einen zusätzlichen Dienst, hat aber einen Nachteil — ändert sich die Adresse, muss der Code neu gedruckt werden. Dynamische Codes mit Weiterleitung erlauben spätere Änderungen, sind aber von einem Anbieter abhängig, der dauerhaft erreichbar bleiben muss.

Die Exportdatei ist ein PNG in der gewählten Pixelgröße. Für den Druck ist eine Auflösung von mindestens 300 dpi sinnvoll; bei 2 Zentimetern Kantenlänge entspricht das rund 240 Pixeln. Der generierte Code enthält keine Rückverfolgung und keinen Zwischendienst.
