Suggested classroom uses

  • Explore possible words from a fixed set of letters.
  • Compare word length, meaning, pronunciation and game score.
  • Practice spelling patterns such as five-letter words and words ending in -ing.
  • Discuss why a candidate word is valid instead of copying an answer without reflection.

Usage notes

Where the badge belongs, and where it does not

The badge is meant for one situation: a page that already recommends tools, and wants a working link next to the recommendation. It is not a banner, and it should not be placed anywhere a reader would mistake it for the site's own branding.

Placement that works

  • A resource list or "useful links" section on a teaching site, where each entry has a one-line description.
  • The end of a blog post that already explains a word-game or vocabulary problem, as the tool the reader can try next.
  • A puzzle community's sidebar, alongside other free tools — not above the community's own content.

Placement that causes problems

  • Inside content aimed at children, without the site's own review — the tool is free and has no accounts, but a badge is still a recommendation, and recommendations in child-facing pages should go through whoever runs the site.
  • On a page that is mostly ads. A badge there reads as paid placement, which it is not, and the confusion lands on both sides.
  • As a header or logo. It is not a co-branding mark, and using it that way implies a partnership that does not exist.

What the link actually contains

The snippet carries three UTM parameters: utm_source=website_badge, utm_medium=referral, and a campaign name. Those exist so that referral traffic can be told apart from search traffic in our own analytics — that is the whole mechanism. There is no third-party pixel in the snippet, no cookie set by the image, and no per-site identifier. If you strip the parameters, the badge still works; you simply become indistinguishable from organic traffic, which is fine.

Attribution, and how to word it

A plain sentence is enough: "Word puzzles and vocabulary tools — HaoWordTool (free)." There is no required wording, and no reciprocal link is expected. If the surrounding copy describes what the tool does, keep it accurate: it finds candidate English words from a supplied set of letters using a bundled word list; it does not check answers against an official dictionary, and it does not score them for a specific game.

The image needs its alt text kept intact. Replacing it with an empty alt makes the link unreadable to screen readers, and removing width and height causes layout shift as the page loads. Both are one-line fixes in the snippet, and both are worth doing.

Corrections: if a page links to a URL that later moves, or if the description next to the badge turns out to be wrong, write to the contact address and it will be fixed at the source rather than asked of every publisher individually. Link rot is expected over years; a wrong description is not.

For teachers adapting the material

The guides may be printed for classroom use and quoted with attribution. They may not be republished in full on another site, because that competes with the original in search results and helps neither party. If a specific worksheet is wanted in an editable format, ask — the answer is usually yes, and it is faster than rebuilding it.
