IP アドレスとは

IP アドレスは、インターネット上のデバイスを識別する番号です。グローバル IP はインターネット接続時に ISP から割り当てられ、プライベート IP は家庭内・社内ネットワークで使用されます。

よくある質問

IP アドレスで何がわかりますか？

おおよその都市、地域、国、ISP（プロバイダ）がわかります。ただし、正確な住所や個人情報は特定できません。

IP アドレスは変わりますか？

はい。多くの ISP は動的 IP を割り当てるため、ルーターの再起動や接続のたびに変わることがあります。

VPN を使うとどうなりますか？

VPN 接続中は、VPN サーバーの IP アドレスが表示されます。元の IP は隠されます。
