Cuenta las letras

Ordena las letras y marca las repeticiones. Una palabra solo es válida para la búsqueda si no usa más copias de una letra de las disponibles.

02

Define la longitud

El modo exacto usa todas las letras; el modo parcial permite palabras más cortas. ? o * representa una ficha en blanco.

Comprueba el contexto

Los diccionarios oficiales cambian según el juego y la región. Verifica las palabras poco comunes en la lista indicada por tus reglas.
