Order handover

How the delivery match works

This page exists because PayPal does not reliably pass a service description back to a seller. The payment arrives with an email address and a transaction ID — often nothing about which product was bought. The form below supplies those two missing pieces.

  1. You pay with PayPal. The payment completes first; this page is the step after the return-to-merchant redirect.
  2. You submit the delivery email. This is where the files go. It can differ from the PayPal account email, which is common when a company card pays and a personal inbox receives.
  3. You add the transaction ID. That is the join key. The email address alone is not unique enough — one address can have several orders open at once.
  4. We match the payment to the order and send the download link or the service delivery link to the address you gave.

Where to find the transaction ID

In PayPal: Activity → open the payment → the ID appears at the top, a 17-character string starting with a digit or letter, formatted like 1AB23456CD789012E. The receipt email PayPal sends contains the same ID near the top. Copy it whole — a truncated ID cannot be matched, and a guessed one will match nothing.

The four reasons a match fails

CauseWhat it looks like
ID mistypedOne character off, or the trailing block lost when copied from a phone screen
Payment still pendingThe transaction sits in eCheck or pending review; the money has not cleared, so there is nothing to match
Email typoThe delivery email differs from the PayPal email and contains a misspelling, so the file goes to an address you do not control
Product not specifiedTwo packages at different prices; without the product field there is no way to tell which one was bought

What you receive, and what you do not

Digital files are delivered as a Google Drive folder link with access granted to the address you submit. No physical item is shipped, and no tracking number will follow — if a page or email mentions shipping, it is not this order. Service work is delivered as a link to the completed deliverable plus the source files where the package includes them.

The delivery email address you type here is stored with the order record for the purpose of matching and re-sending. It is not added to a mailing list, and it is not shared with the payment processor beyond what the payment itself already contains.

Keep the transaction ID. It is the only identifier that survives a browser change, a cleared inbox, or a delivery link that has expired. Google Drive links can be revoked if access is ever tightened; the transaction ID is what lets a link be reissued.
