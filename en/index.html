How these tools actually work

Short version: everything runs inside your browser. The server is not involved.

These tools use capabilities the browser already has — JavaScript for arithmetic, Canvas for QR codes and image processing, the built-in Intl interfaces for currency and date formatting. None of them send your input to a server and wait for a response. That has two consequences: speed depends on your device rather than your connection, and whatever you type never leaves the machine you typed it on.

In several of these cases that matters more than the feature list itself. You do not want a generated password passing through somebody else's server. You do not want the text of a contract or a draft thesis stored as a row in a database you have never seen. You do not want work images uploaded to an object store in an unknown region. Local processing is not a marketing angle here; it is the only sensible design for this category of tool.

Why it is free

Because the cost structure allows it. These are static pages — no backend process, no database, no per-call API bill — so hosting costs approach zero and there is no honest reason to charge. The advertising on the page covers the domain and the bandwidth. There is no membership tier, no export restriction and no three-free-uses-per-day limit.

Does it work on a phone

Yes. Every tool page uses a responsive layout with touch-sized controls, and none of them require horizontal scrolling in portrait. Tools like the calculator, unit converter and QR code generator are arguably more convenient on a phone than on a desktop.

Do I need to install anything

No. There is no installer, no browser extension, no account, and no permission prompt. Open the page and use it; close the page and nothing remains.

About the AI tool growth index

A second section alongside the tools, and the only part of this site that needs continuous updating.

Most tool directories sort by traffic, so the answer is always the same handful of incumbents. That is not actionable for anyone building a product — nobody is going to build another ChatGPT. The useful question is different: over the past month, which AI tool sites almost nobody had heard of multiplied their traffic, which narrow need did they carve out, and how did they acquire users?

So the index sorts on exactly one measure: month-over-month growth. It currently tracks nineteen sites, each verified by hand — the domain resolves, the product does one clearly defined thing, and the growth is real. The sample will expand gradually, and every entry will keep being checked rather than padded.

The traffic figures are third-party estimates, not audited data, and they are good only for reading magnitude and direction. The methodology section says so plainly, because that limitation determines how the data should and should not be used.

Common questions

Are these tools really free

Yes. No membership tiers, no locked features, no usage caps. The site covers its costs through the advertising on the page.

Is my input uploaded or stored

The tools themselves upload nothing and store nothing locally; reloading the page clears your input. The only third-party scripts are analytics and advertising, which measure page visits and do not touch what you type into a tool.

Why is the tool interface in English

Because most search traffic for these tools is in English. Functionality is unaffected by language, and this homepage is available in Chinese through the language switch in the header.

Can I bookmark or share this site

Yes. Share the link directly — there is no invite code and no account required.

What if I find a bug

Tell us through the contact link in the footer, and include which browser you used and the steps you took. It gets fixed in the next pass.
